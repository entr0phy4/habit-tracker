# Phase 3 — UI Design Contract

> Visual and interaction contract for Dashboard & Progress Visualization. Extends Phase 1–2 design system (`01-UI-SPEC.md`, `02-UI-SPEC.md`). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui (initialized — `components.json` present) |
| Preset | `new-york`, `baseColor: zinc`, dark mode default — inherited from Phase 1 |
| Component library | Radix UI primitives (via shadcn) |
| Icon library | lucide-react 1.25.0 |
| Font | Inter (inherited from `src/index.css`) |
| Heatmap library | `react-activity-calendar@3.2.1` (new dependency) |

**Phase 3 adds no new shadcn components.** Reuse existing `button` only where already used. New UI is composed with Tailwind utility classes and `react-activity-calendar`.

**Root dark class:** `<html class="dark">` — unchanged from Phase 1.

**CSS variable mapping:** Unchanged from Phase 1 (`01-UI-SPEC.md`). All tokens live in `src/index.css` `@theme`:

| Token | Hex | Phase 3 usage |
|-------|-----|---------------|
| `--background` | `#0d1117` | Page dominant surface, tab bar background |
| `--card` | `#161b22` | Dashboard habit cards |
| `--border` | `#30363d` | Card borders, tab bar top border, heatmap empty cells |
| `--muted` | `#21262d` | Heatmap not-scheduled cells (very dim) |
| `--muted-foreground` | `#8b949e` | Tab inactive labels, "Historial" subtitle |
| `--foreground` | `#e6edf3` | Habit names, streak counts, active tab label |
| `--primary` | `#3fb950` | Flame icon, completed heatmap cells, active tab icon |
| `--destructive` | `#f85149` | Missed scheduled heatmap cells (ring or tint) |
| `--ring` | `#3fb950` | Focus rings on tab items and heatmap tappable cells |

**`react-activity-calendar` theme mapping:**

```ts
const heatmapTheme = {
  light: ['#21262d', '#0e4429', '#006d32', '#26a641', '#3fb950'],
  dark:  ['#21262d', '#0e4429', '#006d32', '#26a641', '#3fb950'],
};
```

Use `colorScheme="dark"`. Binary completion maps to level `0` (empty/missed base) or level `4` (completed). Not-scheduled cells use level `0` at `opacity-20` via `renderBlock` wrapper — visually distinct from missed scheduled (destructive ring).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0d1117` (`--background`) | Page background, tab bar |
| Secondary (30%) | `#161b22` (`--card`) + `#21262d` (`--muted`) | Dashboard cards, heatmap empty cells |
| Accent (10%) | `#3fb950` (`--primary`) | Flame icon, completed heatmap cells, active tab icon/indicator, FAB (unchanged) |
| Destructive | `#f85149` (`--destructive`) | Missed scheduled heatmap cells (ring outline) |

**Accent reserved for (Phase 3 additions in bold):**

- FAB, selected day toggles, swipe reveal, primary form submit (Phase 1)
- Completed week-overview dots, `Flame` streak icon on Today rows (Phase 2)
- **Active bottom-tab icon and top indicator bar**
- **Completed heatmap cells (level 4 green)**
- **Dashboard card `Flame` icon**

**Destructive reserved for:**

- Hard delete button and confirm dialog (Phase 1)
- Missed scheduled day ring on heatmap cells (D-15) — `ring-2 ring-destructive` on tappable missed cells

**Accent NOT used for:** inactive tab labels, dashboard card backgrounds, not-scheduled heatmap cells, streak count numbers (use `--foreground`).

## Responsive Breakpoints

Inherited from Phase 1:

| Name | Min width | Phase 3 layout behavior |
|------|-----------|-------------------------|
| Mobile | 0px | Bottom tab bar full viewport width, content `max-w-[480px]` centered; heatmap in `overflow-x-auto` horizontal scroll container (D-13, VIZ-01); FAB sits above tab bar |
| Desktop | 768px | Tab bar and content column `max-w-[480px]` centered; heatmap fits without scroll when viewport ≥ 480px; row tap on dashboard cards (no swipe) |

**Heatmap responsive rule (D-13, VIZ-01):** Wrap `ActivityCalendar` in `div` with `overflow-x-auto -mx-4 px-4` on mobile so 52-week grid scrolls horizontally. `showMonthLabels` and `showWeekdayLabels` remain visible; sticky left labels optional at planner discretion — prefer scroll-only (simpler).

**Tab bar:** Always visible at bottom on tab-bar routes; `position: fixed; bottom: 0; left: 0; right: 0; z-index: 40`. Inner content `max-w-[480px] mx-auto`.

### New: `ContributionHeatmap`

**Route context:** `/habits/:id/history` — replaces `HistoryDotGrid` (D-09)

| Property | Spec |
|----------|------|
| Library | `react-activity-calendar@3.2.1` |
| Window | Last 52 weeks from today (D-13) — ~364 days |
| Props | `colorScheme="dark"`; `theme={heatmapTheme}`; `weekStart={1}` (Monday); `blockSize={12}`; `blockMargin={3}`; `showWeekdayLabels`; `showMonthLabels` |
| Data | Array of `{ date: 'YYYY-MM-DD', count: 0|1, level: 0|4 }` from `domain/heatmap.ts` |
| Container | `overflow-x-auto -mx-4 px-4` wrapper for mobile horizontal scroll (VIZ-01) |
| Loading | Return `null` while completions loading |

**Visual states (schedule-aware, D-14, D-15):**

| State | Condition | Visual |
|-------|-----------|--------|
| `completed` | Scheduled + completion exists | Level 4 green (`#3fb950`); tappable |
| `missed` | Scheduled + past/today + no completion | Level 0 cell + `ring-2 ring-destructive` wrapper; tappable |
| `not-scheduled` | `!isDueOnDate(frequency, date)` | Level 0 at `opacity-20`; **not tappable** — no ring |
| `future` | Scheduled + future date | Level 0 at `opacity-40`; disabled; not tappable (D-16) |
| `today` | `date === todayKey` | Additional `ring-2 ring-primary` on wrapper (stacks with missed ring if applicable) |

**Interaction (D-16):**

| State | Tappable | Action |
|-------|----------|--------|
| `completed` | Yes | Toggle off via `useToggleCompletion` |
| `missed` | Yes | Toggle on |
| `not-scheduled` | No | Pointer events none |
| `future` | No | Disabled |

**Touch targets (UI-02):** `renderBlock` wraps each cell in a `button` or `div` with `min-h-11 min-w-11 flex items-center justify-center` for scheduled tappable days; not-scheduled cells render without button wrapper (visual only).

**Tooltip (D-15):** Use library tooltip or `renderBlock` title attribute with Spanish copy per state. Format: `{weekday} {day} {month} — {status}` using `date-fns` `format` with `es` locale optional — English month abbreviations acceptable if locale not wired: "Mon 14 Jul — Completado".

**Toggle error:** Sonner toast "Couldn't update. Try again." on failure.

**Performance:** Memoize activity data array; `React.memo` on heatmap component; compute in `domain/heatmap.ts` outside render.

## Accessibility

| Requirement | Phase 3 implementation |
|-------------|------------------------|
| Touch targets | Dashboard cards `min-h-11`; tab items ≥ 44px; heatmap tappable cells wrapped to 44×44px via `renderBlock` |
| Screen reader — tabs | `role="tablist"` / `role="tab"` / `aria-selected` |
| Screen reader — dashboard cards | `aria-label` with habit name and streak count |
| Screen reader — heatmap | Tappable cells: `aria-pressed` + `aria-label="{date} {status}"`; not-scheduled cells excluded from tab order |
| Color contrast | Heatmap greens on `#0d1117` used for cells ≥ 3×3px — decorative; status also in tooltip text |
| Motion | Press animations < 200ms; heatmap scroll is user-controlled — no auto-scroll |
| Keyboard | Dashboard cards focusable; heatmap tappable cells focusable buttons; tab bar keyboard navigable |
