# Phase 6 — UI Design Contract

> Visual and interaction contract for Dashboard Aggregate & UAT Residual. Extends Phase 1–5 design system. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui (initialized — `components.json` present) |
| Preset | `new-york`, `baseColor: zinc`, dark mode default — inherited |
| Component library | Radix UI primitives (via shadcn) — **no new shadcn components** |
| Icon library | lucide-react (existing `Flame` on cards unchanged) |
| Font | Inter (inherited from `src/index.css`) |

**Phase 6 adds no new shadcn components and no new npm packages.** Overall rate is plain HTML (`dl`/`div`) matching `StatCards` typography patterns.

**Root dark class:** `<html class="dark">` — unchanged.

**Global CSS variable mapping:** Unchanged from Phase 1 (`src/index.css` `@theme`):

| Token | Hex | Phase 6 usage |
|-------|-----|---------------|
| `--background` | `#0d1117` | Panel page surface |
| `--card` | `#161b22` | Optional summary surface; DashboardCard unchanged |
| `--border` | `#30363d` | Optional summary border if card-like container used |
| `--muted-foreground` | `#8b949e` | "Tasa general" label |
| `--foreground` | `#e6edf3` | Overall percent value |
| `--primary` | `#3fb950` | Unchanged global chrome; Phase 5 may tint Flame per habit if shipped |

**Do not** introduce purple accents, glow, or new metric colors for the overall rate — value uses `--foreground` like StatCards numbers.

## Layout — Panel (`DashboardPage`)

**Route:** `/dashboard`

### Populated (active habits ≥ 1)

```text
AppShell title="Panel"
┌─────────────────────────────────────┐
│  Tasa general                       │  ← label
│  72%                                │  ← value
│                                     │  gap ~8–16px
│  ┌───────────────────────────────┐  │
│  │ Habit A          🔥 12        │  │  DashboardCard (unchanged)
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │ Habit B          🔥 3         │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

| Property | Spec |
|----------|------|
| Summary placement | Content region **above** the `<ul>` of cards (D-01); **not** in AppShell title |
| Summary container | Prefer minimal: no heavy card chrome required. Allowed: plain block OR light `rounded-lg border border-border bg-card p-3` single metric — **not** a 3-column StatCards grid |
| Cards | Unchanged — name + Flame + streak only (D-01 / Phase 3 D-05) |
| Sort | `currentStreak` descending (unchanged) |
| Bottom padding | `pb-20` |

### Empty (active habits = 0, status ready)

| Property | Spec |
|----------|------|
| Overall summary | **Hidden** (D-04) |
| Empty state | Existing centered empty state owns viewport |

### Denominator 0 (habits exist, no scheduled days yet)

| Property | Spec |
|----------|------|
| Summary | Visible |
| Value | **`0%`** (D-04) |

### Loading

| Property | Spec |
|----------|------|
| Render | `null` while `status === 'loading'` / `isLoading` (unchanged Phase 1/3 pattern) |

### Error (IndexedDB read failure)

| Property | Spec |
|----------|------|
| Overall summary | **Hidden** |
| Body | Centered muted text: **No se pudieron cargar los hábitos.** |
| Forbidden | Raw `Error` / Dexie / stack strings (D-14) |

## Component Contract — Overall rate summary

Inline in `DashboardPage` (no mandatory new file). If extracted:

| Prop | Type | Notes |
|------|------|-------|
| `rate` | `number` | Whole percent 0–100+ (round already applied) |
| `visible` | derived | Only when `status === 'ready' && items.length > 0` |

Accessibility:

| Requirement | Spec |
|-------------|------|
| Semantics | Prefer `<dl>` with one `<dt>`/`<dd>` pair or labeled text with `aria-label="Tasa general"` on the value region |
| Interactive | No — display only |
| Live region | Not required; page re-render on live query is enough |

## QA-01 UI Behaviors (no redesign)

### Reactive stats (UAT #1)

| Surface | Expected after toggle |
|---------|------------------------|
| Today `HabitRow` Flame count | Updates without reload |
| History `StatCards` Current/Longest/Rate | Updates without reload |
| Heatmap cell | Completes/misses update (reinterpret "dot grid") |
| Panel "Tasa general" | Updates when completions change (ENH-03 / D-08) |

### Dexie failure (UAT #2 / #3 / Phase 3 WR-02)

| Hook | UI result |
|------|-----------|
| `useStreak` | Flame shows `0` (or hidden if loading null pattern already resolved) — no exception text |
| `useHabitStats` | StatCards show `0` / `0%` after load resolves — no exception text |
| `useDashboardHabits` | Soft error message; no cards; no rate; no exception text |

### Large integers (UAT #4)

| Component | Spec |
|-----------|------|
| `StatCards` | `String(current)` / `String(longest)` — e.g. `1234`, `5678` — **no** K/M abbreviation |
