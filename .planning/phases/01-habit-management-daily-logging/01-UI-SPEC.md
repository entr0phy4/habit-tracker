## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Dot grid gaps, icon-to-label gap |
| sm | 8px | Inline icon padding, dot internal spacing |
| md | 16px | Page horizontal padding, row internal padding, FAB offset from edge |
| lg | 24px | Section gaps (header → list, form field spacing) |
| xl | 32px | Form page top padding below header |
| 2xl | 48px | Bottom padding on Today list (clears FAB) |
| 3xl | 64px | Unused in Phase 1 |

| Exception | Value | Usage |

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0d1117` (`--background`) | Page background, app shell |
| Secondary (30%) | `#161b22` (`--card`) + `#21262d` (`--muted`) | Habit rows, form card surfaces, input backgrounds |
| Accent (10%) | `#3fb950` (`--primary`) | FAB, selected day toggles, completed dots, swipe reveal, focus rings, primary form submit |
| Destructive | `#f85149` (`--destructive`) | Hard delete button, destructive confirm dialog actions |

**Accent reserved for:**

- FAB background and icon
- Selected day-of-week toggle buttons (frequency picker)
- Completed state dots (week schedule indicator + history dot grid)
- Swipe-right completion reveal strip
- Primary form submit button ("Create habit" / "Save changes")
- Focus ring on keyboard-focused controls

**Accent NOT used for:** navigation links, history chevron, archive actions, body text, borders, incomplete dots.

**Completed row treatment (D-11):** `background: --muted`, habit name `color: --muted-foreground` + `text-decoration: line-through`.

**Incomplete dot:** `#30363d` fill, 8px diameter circle.

**Complete dot:** `#3fb950` fill, 8px diameter circle.

**Today indicator on history dot:** 2px `#3fb950` ring around dot (dot may be filled or empty).

| Toast (edit success) | **Habit updated** |
| Toast (archive success) | **Habit archived** |

| Destructive confirmation (archive) | No dialog — archive is reversible from Manage screen; toast only |
| History screen subtitle | **Last 7 days** |
| Manage habits link | **Manage habits** |
| Back navigation | **Back** (with chevron-left icon) |

## Responsive Breakpoints

| Name | Min width | Layout behavior |
|------|-----------|-----------------|
| Mobile | 0px | Full-width content; `padding-inline: 16px`; FAB `bottom: 16px; right: 16px`; swipe-to-complete enabled |
| Desktop | 768px | Content column `max-width: 480px`, horizontally centered; row tap-to-toggle (no swipe); increased list `padding-bottom: 64px` |

**Detection:** Use `(pointer: coarse)` and `pointerType === 'touch'` for swipe vs tap — not viewport width alone. Desktop breakpoint governs layout width only.

### `TodayView`

**Route:** `/` (index)

| Property | Spec |
|----------|------|
| Header | `Heading` "Today" left-aligned; `Manage habits` text link right-aligned (`text-sm`, `--muted-foreground`, hover `--foreground`) → `/habits/manage` |
| List | Flat vertical stack, `gap: 8px`, scrollable (`overflow-y: auto`), habits due today only (D-01, D-02) |

### `HabitRow`

| Property | Spec |
|----------|------|
| Min height | 44px (`min-h-11`) |
| Layout | Flex row: `[name + WeekDayDots]` flex-1 \| `[history button]` 44×44 |
| Background | `--card` default; `--muted` when complete |
| Border | `1px solid --border`, `border-radius: 8px` |
| Padding | `12px 16px` (vertical achieves 44px+ with single-line name) |
| Name | `Body` typography; `line-through` + `--muted-foreground` when complete |
| WeekDayDots | Inline right of name (or below name on narrow screens if name wraps — dots stay on same row as name when possible) |
| History affordance | Trailing `Button` variant `ghost` size `icon` (44×44), `CalendarDays` lucide icon, `aria-label="Edit history for {habitName}"` → navigates `/habits/:id/history` |
| Toggle zone | Entire row EXCEPT history button triggers completion toggle |

**Interaction split (resolves RESEARCH open question):** Row body = toggle; trailing icon = navigate. Prevents accidental history navigation on toggle.

| Property | Spec |
|----------|------|

## Interaction States

### `HabitRow` states

| State | Visual | Trigger |
|-------|--------|---------|
| Default | `--card` bg, normal name color | Incomplete habit |
| Complete | `--muted` bg, name strikethrough + `--muted-foreground` (D-11) | Toggled on for today |
| Pressed | `transform: scale(0.98)`, 100ms ease | `pointerdown` on row body |
| Swiping | Row translates `translateX(min(deltaX, 80px))`; green (`#3fb950` at 20% opacity) strip revealed on left edge | `pointerType: touch`, horizontal drag > 10px |
| Swipe complete | On release with `deltaX > 50px` and `deltaX > deltaY`: toggle + snap back to `translateX(0)` | D-09 |
| Hover (desktop) | `background: #1c2128` (slightly lighter than card) | `:hover` on pointer fine devices |

**Desktop toggle (D-10):** `onClick` on row body when `pointerType !== 'touch'` (or last interaction was mouse).

**Undo (D-12):** Same gesture toggles off — no separate undo UI.

### `HabitForm` day toggle states

| State | Visual |
|-------|--------|
| Unselected | `--card` bg, `--border` outline |
| Selected | `--primary` bg, `--primary-foreground` text |
| Focus | `--ring` 2px outline |
| Pressed | `scale(0.97)` |

### `WeekDotGrid` dot states

| State | Visual |
|-------|--------|
| Incomplete | Gray dot `#30363d` |
| Complete | Green dot `#3fb950` |
| Today (incomplete) | Gray dot + green ring |
| Today (complete) | Green dot + green ring |
| Pressed | `scale(0.9)` on dot button |

### `FAB` states

| State | Visual |
|-------|--------|
| Default | Green circle, shadow |
| Hover | `brightness(1.1)` |
| Pressed | `scale(0.95)` |
| Focus | `--ring` outline 2px offset |

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Touch targets | All interactive elements ≥ 44×44px |
| Swipe alternative | Desktop row tap (D-10); history dots are keyboard-focusable buttons |
| Focus visible | shadcn default focus rings on all controls |
| Screen reader | FAB `aria-label`; history button `aria-label` per habit; day toggles expose `aria-pressed` |
| Motion | Press/swipe animations < 200ms; no required motion to complete actions |
| Color contrast | `#e6edf3` on `#0d1117` ≥ 4.5:1; `#3fb950` on `#0d1117` used for dots/icons only, not small text |
