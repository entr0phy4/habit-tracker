# Phase 2 — UI Design Contract

> Visual and interaction contract for Streaks & Statistics. Extends Phase 1 design system (`01-UI-SPEC.md`). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui (initialized — `components.json` present) |
| Preset | `new-york`, `baseColor: zinc`, dark mode default — inherited from Phase 1 |
| Component library | Radix UI primitives (via shadcn) |
| Icon library | lucide-react 1.25.0 |
| Font | Inter (inherited from Phase 1 `src/index.css`) |

**Phase 2 adds no new shadcn components.** Reuse existing `button` only where already used. New UI is composed with Tailwind utility classes on plain `div`/`span` elements (`StatCards`, streak badge).

**Root dark class:** `<html class="dark">` — unchanged from Phase 1.

**CSS variable mapping:** Unchanged from Phase 1 (`01-UI-SPEC.md`). All tokens live in `src/index.css` `@theme`:

| Token | Hex | Phase 2 usage |
|-------|-----|---------------|
| `--background` | `#0d1117` | Page dominant surface |
| `--card` | `#161b22` | Stat card surfaces |
| `--border` | `#30363d` | Stat card borders, incomplete dot fill |

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0d1117` (`--background`) | Page background |
| Secondary (30%) | `#161b22` (`--card`) + `#21262d` (`--muted`) | Stat cards, habit rows |
| Accent (10%) | `#3fb950` (`--primary`) | Completed dots, streak `Flame` icon, today ring, swipe reveal (unchanged) |
| Destructive | `#f85149` (`--destructive`) | Hard delete (Phase 1) **+ missed scheduled day ring** (Phase 2, D-11) |

**Accent reserved for (Phase 2 additions in bold):**

- FAB, selected day toggles, swipe reveal, primary form submit (Phase 1)
- Completed week-overview dots (green fill)
- **`Flame` streak icon on Today rows**
- **Today ring on history dot grid**

**Destructive reserved for:**

- Hard delete button and confirm dialog (Phase 1)
- **Missed scheduled day outline ring on history dot grid** (D-11) — empty circle with `ring-2 ring-destructive`, no X mark, no fill

**Accent NOT used for:** stat card values (use `--foreground`), stat labels, missed dots (use destructive ring only), streak count number (use `--foreground`).

**Completed row treatment (D-04):** Streak badge remains at full opacity and `--primary` flame color when row is complete — badge is NOT muted with the strikethrough name.

## Responsive Breakpoints

Inherited from Phase 1:

| Name | Min width | Phase 2 layout behavior |
|------|-----------|-------------------------|
| Mobile | 0px | Stat cards: `grid grid-cols-3 gap-2` with compact padding; if viewport < 320px, cards remain 3-column (values truncate gracefully). Alternative at planner discretion: horizontal scroll row with `overflow-x-auto` and `min-w-[88px]` per card — prefer 3-column grid at all mobile widths since values are short numerics. |
| Desktop | 768px | Stat cards: `grid grid-cols-3 gap-4`, equal width; content column `max-w-[480px]` centered (unchanged) |

**Stat cards responsive rule (D-05 discretion):** Three equal cards in a single row at all breakpoints. On narrow mobile, reduce card padding (`p-2` mobile, `p-3` desktop) rather than stacking — numeric values are 1–3 characters and fit. If stacking is needed at extreme narrow widths, stack vertically with `grid-cols-1` below 280px only (backstop — verify in UAT).

**History dot grid:** Always 7 columns Mon–Sun; `gap-4` (16px) between columns; centered horizontally. Non-scheduled columns render empty spacer (`w-11`) to preserve alignment.

## Component Inventory

### Modified: `HabitRow` (Today view streak badge)

**Route context:** `/` — Today list

| Property | Spec |
|----------|------|
| Layout change | `[name] [streak badge] [WeekDayDots] [history button]` — flex row, `gap-3` between zones |
| Streak badge position | Immediately after truncated habit name, before `WeekDayDots` (D-01) |
| Streak badge content | `Flame` lucide icon (16×16px, `text-primary`) + streak count (`text-xs font-semibold text-foreground`, 4px gap) |
| Visibility | Always rendered for every due habit row — including when `isCompleted` is true (D-04) |
| Zero streak | Show `Flame` + `0` until first scheduled day is completed (D-13) — do not hide badge at zero |
| Data source | `useStreak(habit)` hook — reactive via `useLiveQuery` |
| Row min height | 44px unchanged (`min-h-11`) |
| Name truncate | Unchanged — `truncate` on name span; badge and dots are `shrink-0` |
| Completed row | Name: strikethrough + `--muted-foreground`; badge: **full color, no opacity reduction** |
| Accessibility | Badge wrapper: `aria-label="{currentStreak} day streak"`; `aria-hidden` on decorative `Flame` if label is on wrapper |

**Interaction:** Streak badge is not separately tappable — row body toggle behavior unchanged.

### Modified: `HistoryDotGrid` (calendar week overview)

**Route context:** `/habits/:id/history`

| Property | Spec |
|----------|------|
| Week range | Calendar week Mon–Sun containing today (D-09) — replaces rolling last-7-days |
| Day labels | Single letter per column: Mon=`M`, Tue=`T`, Wed=`W`, Thu=`T`, Fri=`F`, Sat=`S`, Sun=`S` — always 7 labels even when dot is hidden (D-09, RESEARCH recommendation) |
| Column order | Monday left → Sunday right |
| Dot touch target | 44×44px (`h-11 w-11`) — upgraded from Phase 1 `h-8 w-8` for UI-02 compliance |
| Visible dot size | 12px inner circle centered in touch target |
| Subtitle (parent page) | "This week" replaces "Last 7 days" |

**Visual states (D-10, D-11):**

| State | Condition | Visual |
|-------|-----------|--------|
| `completed` | Scheduled + completion exists | Green filled inner dot (`bg-primary`); optional `bg-primary/10` on button background |
| `missed` | Scheduled + past/today + no completion | Empty inner dot (`bg-transparent`); `ring-2 ring-destructive` on 44px button — no X mark |
| `not-scheduled` | `!isDueOnDate(frequency, date)` | **Hidden dot** — render empty `div` spacer `w-11 h-11` (no button); day label still visible |
| `future` | Scheduled + future date | Dimmed button (`opacity-40`), disabled, gray inner dot; NOT counted as missed |
| `today` | Any state where `date === today` | Additional `ring-2 ring-primary` on button (stacks with missed destructive ring if today is missed) |

**Interaction:**

| State | Tappable |
|-------|----------|
| `completed` | Yes — tap toggles off |
| `missed` | Yes — tap toggles on |
| `not-scheduled` | No — no button rendered |
| `future` | No — `disabled` |

**Toggle error:** Sonner toast "Couldn't update. Try again." on failure (existing pattern).

**Props change:** Accept `frequency: Frequency` prop (passed from `HabitHistoryPage`) for schedule-aware state resolution via `getWeekDayState()`.

## Interaction States

### Streak badge states (`HabitRow`)

| State | Visual |
|-------|--------|
| Default (incomplete row) | Green `Flame` + count in `--foreground` |
| Complete row | Same badge styling — no mute, no hide (D-04) |
| Streak = 0 | `Flame` + `0` displayed |
| Loading | Badge hidden until `useStreak` resolves (row renders without badge briefly — acceptable <100ms) |

### Stat card states

| State | Visual |
|-------|--------|
| Populated | Label + value as specified |
| Loading | Entire `StatCards` row not rendered |
| Zero values | `0`, `0`, `0%` — valid populated display, not empty state |

### History dot states

| State | Visual | Interaction |
|-------|--------|-------------|
| Completed | Green fill + optional green bg tint | Tap toggles off |
| Missed | Red destructive ring, empty center | Tap toggles on |
| Not scheduled | No dot, label only | None |
| Future scheduled | Gray dot, 40% opacity | Disabled |
| Today + completed | Green fill + primary ring | Tap toggles off |
| Today + missed | Destructive ring + primary ring (nested) | Tap toggles on |
| Pressed | `active:scale-90` on tappable dots | — |

**Reactive update (ROADMAP criterion 5):** All stats and dots recalculate immediately on toggle via `useLiveQuery` — no manual refresh, no stale values.

## Accessibility

| Requirement | Phase 2 implementation |
|-------------|------------------------|
| Touch targets | History dots upgraded to 44×44px; streak badge is decorative inline (row body remains 44px min) |
| Screen reader — streak | `aria-label="{n} day streak"` on badge container |
| Screen reader — stats | Stat cards use semantic `<dl>`/`<dt>`/`<dd>` or `role="group"` with `aria-label="Habit statistics"` |
| Screen reader — missed dots | `aria-pressed={false}` on missed tappable dots; `aria-label="{day} missed, tap to complete"` |
| Screen reader — not-scheduled | Column label present; no interactive element — no misleading button |
| Color contrast | Destructive ring `#f85149` on `#0d1117`/`#161b22` ≥ 3:1 for non-text UI indicator |
| Motion | Dot press `scale(0.9)` < 200ms — unchanged from Phase 1 |
