## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backup file → parseBackupJson | Untrusted JSON may include arbitrary color strings |
| normalizeHabitColor → style/DB write | Only /^#[0-9a-f]{6}$/ or default may leave the domain layer |
| Dexie upgrade → habits table | Local migration; no network |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering / Injection | habit.color from import or free data | medium | mitigate | normalizeHabitColor to /^#[0-9a-f]{6}$/ only before style or storage; never interpolate raw strings into CSS selectors |
| T-05-02 | Tampering | backupSchema invalid color | low | mitigate | Invalid/missing color → DEFAULT_HABIT_COLOR; do not fail import solely for bad color (D-04) |
| T-05-03 | Elevation of Privilege | Dexie v2 upgrade | low | accept | Local-only IndexedDB; no auth surface |
| T-05-04 | Information Disclosure | habit red vs destructive | low | mitigate | Habit #f85149 is identity data only; destructive UI tokens unchanged (enforced in UI plans) |
</threat_model>
