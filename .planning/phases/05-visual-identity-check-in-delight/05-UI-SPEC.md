## Habit Color Palette (ENH-01)

Fixed presets — **exactly 8**. Order shown left→right in the form swatch row.

| Key | Hex | Name (aria) | Notes |
|-----|-----|-------------|-------|
| green | `#3fb950` | Green | Default for new + migrated habits; matches `--primary` |
| blue | `#58a6ff` | Blue | GitHub accent blue |
| purple | `#bc8cff` | Purple | Distinct from blue |
| pink | `#f778ba` | Pink | |
| orange | `#ffa657` | Orange | |
| yellow | `#e3b341` | Yellow | |
| cyan | `#39c5cf` | Cyan | |
| coral | `#ff7b72` | Coral | Distinct from destructive `#f85149` |

**Contrast rule:** Every swatch fill must remain clearly visible on `#0d1117` and `#161b22`. Do not add washed-out pastels.

**Storage:** Persist the hex string on `Habit.color` (e.g. `"#3fb950"`). Do not store palette keys — hex is source of truth for heatmap derivation and accents.

**Default:** `#3fb950` when creating a habit if user never changes selection; same default when migrating / importing v1 backups (CONTEXT D-03, D-15, D-16).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0d1117` | Background |
| Secondary (30%) | `#161b22` / `#21262d` | Cards, completed rows, heatmap empty |
| Accent (10%) — app | `#3fb950` | FAB, tabs, primary buttons, focus rings **only** |
| Accent (10%) — habit | `habit.color` | Left rail, Flame, WeekDayDots scheduled fill, heatmap completed levels |
| Destructive | `#f85149` | Missed heatmap rings; errors |

**App accent reserved for (unchanged chrome):**

- FAB, primary form submit, selected day toggles (frequency), bottom tab active icon/indicator, focus rings

**Habit accent reserved for:**

- `HabitRow` 3px left rail
- `HabitRow` / `DashboardCard` `Flame` icon fill/stroke
- `WeekDayDots` scheduled-day filled dots
- Heatmap **completed** cell levels (derived scale)
- Check-in delight flash tint (habit color at ~25% opacity)

**Habit accent NOT used for:**

- Completed row background (stays `--muted`)
- Full card/row flood fill at rest
- FAB / tabs / primary buttons / focus rings
- Missed heatmap treatment (stays destructive ring)
- Heatmap empty base (stays `#21262d`)

## Heatmap Theme Derivation

Replace hard-coded GitHub-green `heatmapTheme` with a function of `habit.color`:

```ts
// Pseudocode contract — planner implements pure helper in domain/
function buildHeatmapTheme(habitColor: string): { dark: string[] } {
  return {
    dark: [
      '#21262d',           // level 0 — empty (fixed)
      mix(habitColor, '#0d1117', 0.25), // level 1
      mix(habitColor, '#0d1117', 0.50), // level 2
      mix(habitColor, '#0d1117', 0.75), // level 3
      habitColor,          // level 4 — completed (binary uses 0 | 4 today)
    ],
  };
}
```

- `mix(fg, bg, t)` = linear RGB (or OKLCH) blend; exact algorithm at planner discretion if contrast preserved
- Missed / today stroke behavior unchanged: `var(--destructive)` / `var(--primary)` on SVG stroke (today ring stays **app** primary so "today" affordance is consistent across habits)
- `colorScheme="dark"` unchanged; binary completion still maps to level `0` or `4`
