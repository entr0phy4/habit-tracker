### Per-habit accent override (ENH-01)

When a habit has `color` (always after D-01/D-03), the following surfaces use **`habit.color` instead of `--primary`**:

| Surface | Override |
|---------|----------|
| `HabitRow` left accent bar | `habit.color` fill, 3–4px |
| `HabitRow` swipe-reveal strip | `habit.color` at 20% opacity |
| `HabitRow` `WeekDayDots` scheduled dots | `habit.color` fill |
| `HabitRow` completed background wash | `habit.color` at 15–20% opacity over `--card`/`--muted` |
| `HabitRow` check-in pulse wash | `habit.color` at ~20% opacity during animation |
| `DashboardCard` left accent bar | `habit.color` fill, 3–4px |
| `DashboardCard` `Flame` icon | `habit.color` (`style={{ color }}` or inline) |
| `ContributionHeatmap` `theme.dark` | 5-stop scale derived from `habit.color` |
| `ContributionHeatmap` today stroke | `habit.color` (missed stays `--destructive`) |
| `ManageHabitsPage` identity swatch | `habit.color` circle |

**Global chrome that stays `--primary` `#3fb950`:** FAB, bottom tab active icon/indicator, HabitForm day-of-week toggles, primary form submit, Settings export button, focus rings on non-swatch controls.

**DashboardCard card border:** remains `border-border` — **do not** tint the full card border with habit color (left bar + flame only).

| State | Background formula |
|-------|--------------------|

### Heatmap 5-stop theme from habit hex (D-11, D-18)

Empty cell always `#21262d`. Filled scale is a single-hue ramp ending at the habit hex (level 4).

**Algorithm (domain helper `buildHeatmapTheme(hex)` in `src/domain/habitColors.ts`):**

1. Parse hex → HSL.
2. Build 5 stops for `theme.dark` / `theme.light` (identical arrays for dark-only app):

| Level | Derivation | Example for `#3fb950` (green) |
|-------|------------|-------------------------------|
| 0 | Fixed `#21262d` | `#21262d` |
| 1 | Same hue/sat; lightness ≈ 12–16% (darkest tint) | `#0e4429` class of tone |
| 2 | Mid-dark (~22–28% L) | e.g. `#006d32`-equivalent for habit hue |
| 3 | Mid-bright (~35–42% L) | e.g. `#26a641`-equivalent |
| 4 | Exact habit hex | `#3fb950` |

Implementation may use fixed opacity overlays of habit color on `#0d1117` at ~25% / 45% / 70% / 100% instead of pure HSL, as long as:

- Level 0 is exactly `#21262d`
- Level 4 is exactly `habit.color`
- Stops are monotonically brighter and remain one hue family (not a rainbow)

**Binary completion mapping unchanged:** level `0` or `4` only.

**Strokes:** today → `habit.color`; missed → `--destructive` `#f85149`.

### Contrast (D-18)

- Palette accents on `#0d1117` / `#161b22` for bars, dots, icons (≥3×3px decorative) — readable as identity cues.
- Do not use habit yellow/orange as small body text.
- Destructive actions remain red buttons; habit red `#f85149` is fill/identity only on bars/dots/flame/heatmap — never as the sole meaning of an error without text.

## Interaction / Motion

### Check-in micro-animation (D-13, D-16, D-17)

| Property | Spec |
|----------|------|
| Name | `@keyframes habit-check-in-pulse` |
| Duration | **180ms** (≤200ms hard cap) |
| Easing | `cubic-bezier(0.22, 1, 0.36, 1)` (ease-out) |
| Transform | `scale(1)` → `scale(1.02)` at 40% → `scale(1)` at 100% |
| Background | Simultaneously apply habit-color wash ~20% opacity; settle to resting 18% wash |
| Trigger | Class e.g. `animate-habit-check-in` added on complete; remove on `animationend` |
| Scope | `HabitRow` outer/content surface only — not whole page |
| Uncomplete | No keyframes |
| Panel / heatmap | No check-in animation |

### `prefers-reduced-motion: reduce`

```css
@media (prefers-reduced-motion: reduce) {
  .animate-habit-check-in {
    animation: none;
  }
}
```

Still apply completed color wash **instantly**. Existing `active:scale-[0.98]` may be disabled under reduced motion at implementer discretion; check-in keyframes **must** be skipped.

### Other motion

| Interaction | Spec |
|-------------|------|
| Row / card press | Existing `active:scale-[0.98]` ~100ms |
| Swatch hover | Optional ≤100ms scale 1.05 |
| Swipe | Unchanged thresholds; strip uses habit color |
| Libraries | **Forbidden:** framer-motion, Lottie, canvas confetti, haptic APIs |
