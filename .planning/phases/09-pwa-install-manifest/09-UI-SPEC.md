## Spacing Scale

Inherited 8-point scale. Phase 9 additions:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between banner icon and text; step number → label gap |
| sm | 8px | Banner internal padding vertical; button gap in banner actions |
| md | 16px | Banner horizontal padding; modal padding (`p-6`); Settings section `gap-2` |
| lg | 24px | Modal step list gap (`gap-6` between steps) |
| xl | 32px | — |
| 2xl | 48px | — |
| 3xl | 64px | — |
| touch-min | 44px | All install CTAs and dismiss — `min-h-11 min-w-[44px]` |
| tab-bar-height | 56px | `h-14` — banner `bottom` offset anchor |
| content-max | 480px | `max-w-[480px] mx-auto` — banner and modal width cap |

**Exceptions:**

| Exception | Value | Reason |
|-----------|-------|--------|
| Banner action row | `min-h-11` buttons, compact horizontal layout | Mobile thumb reach above tab bar |
| iOS step Share icon | 20×20px (`h-5 w-5`) inline with step text | Visual anchor without oversized chrome |
| Safe area | `env(safe-area-inset-bottom)` on banner bottom offset | iOS home indicator clearance above tab bar |

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 | Banner body, Settings description, modal step text, Android fallback |
| Label | 12px (`text-xs`) | 600 (`font-semibold`) | 1.5 | Settings section heading "Instalar app" — matches "Copia de seguridad" pattern |
| Heading | 18px (`text-lg`) | 600 (`font-semibold`) | 1.2 | iOS install modal title |
| Display | 20px (`text-xl`) | 600 (`font-semibold`) | 1.2 | Unchanged — AppShell page title "Ajustes" |

**Banner headline:** 14px semibold (`text-sm font-semibold`) — one line preferred; wraps on narrow screens.

**Step numbers:** 14px semibold, `text-primary` — prefix "1.", "2.", "3." inline with step label.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0d1117` | `bg-background` — page, manifest colors, icon background |

**Accent reserved for:** "Instalar app" / "Instalar" / "Cómo instalar" primary buttons; inline step number prefixes in iOS modal; app icon flame fill; focus-visible ring on interactive install controls. **Not** used for dismiss ("Ahora no"), modal close, or informational body text.

**Banner overlay:** No full-screen scrim. Banner uses `border-t border-border bg-card` — distinct from page background, not accent-filled.

## Layout — Install Banner

```text
┌──────────────────────────────────────── max-w 480px ────────────────────────────────────────┐
│  [optional 32px app icon]  Instala para usar sin conexión                                    │
│                            Accede más rápido desde tu pantalla de inicio.                    │
│                            [ Instalar app ]  [ Ahora no ]                                    │
├──────────────────────────────────────────────────────────────────────────────────────────────┤
│  Hoy  │  Panel          ← BottomTabBar (h-14, z-40)                                          │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

| Property | Spec |
|----------|------|
| Position | `fixed inset-x-0 z-45` — above `BottomTabBar` (`z-40`), below FAB/modal (`z-50`) |
| Bottom offset | `bottom: calc(3.5rem + env(safe-area-inset-bottom))` — sits directly above 56px tab bar |
| Width | `mx-auto max-w-[480px] px-4` inner content |
| Surface | `bg-card border-t border-border shadow-[0_-4px_12px_rgba(0,0,0,0.25)]` |
| Padding | `py-3 px-4` (12px vertical, 16px horizontal) |
| Visibility | MainLayout routes only (`/` and `/dashboard`); **not** on Settings, habit forms, or history |
| Engagement gate | Show after **2nd visit OR first check-in** (D-06) — whichever is detected first |
| Dismiss | "Ahora no" → hide **7 days** (D-09); store timestamp in localStorage |
| Standalone | Hidden when `display-mode: standalone` or `navigator.standalone === true` |
| Android CTA | "Instalar app" → trigger deferred `beforeinstallprompt` (D-10) |
| iOS CTA | "Instalar app" → open `IosInstallModal` (D-14) — no native prompt |
| Icon (optional) | 32×32 rounded app icon preview left of headline — use `public/icons/icon-192.png` |

**Action row:**

| Button | Variant | Class |
|--------|---------|-------|
| Instalar app | `default` (primary) | `min-h-11` |
| Ahora no | `ghost` or `outline` | `min-h-11 text-muted-foreground` |

**Content padding adjustment:** When banner visible on tab-bar pages, add `pb-[calc(5.5rem+banner-height)]` or equivalent so list content is not obscured. Banner height ≈ 88–96px depending on wrap.

**Toast coexistence:** Sonner `bottom-center` toasts render at default offset; banner sits lower. Toasts may overlap banner briefly — acceptable; do not reposition Toaster in this phase.

**FAB coexistence:** `FloatingAddButton` at `bottom-[4.5rem] z-50` — when banner visible, FAB remains above banner; no FAB position change required.

## App Icon Visual Spec

Deliberate departure from green-check `public/favicon.svg` (D-01). New assets in `public/icons/`.

| Property | Spec |
|----------|------|
| Motif | **Streak flame** — single upward flame shape, simple geometric, readable at 48px |
| Flame color | `#3fb950` (matches `--primary`) |
| Background | `#0d1117` (matches `--background`) |
| Shape | Rounded square — corner radius **~25%** of edge (e.g. `rx="8"` on 32px unit → scale proportionally: 64px radius on 256, 128px on 512) |
| Maskable safe zone | Flame centered within **80% central safe area**; background fills full canvas including corners |
| Sizes | **192×192** PNG (`icon-192.png`), **512×512** PNG (`icon-512.png`) — maskable purpose |
| Apple touch | **180×180** PNG (`apple-touch-icon.png`) — same visual, no transparency requirement |
| Favicon | Optional SVG `public/icons/icon.svg` for browser tab — same motif |
| Manifest | `name: "Habit Tracker"`, `short_name: "Habit Tracker"` (abbreviate only if iOS truncates — default full name, D-04) |
| Display | `standalone` (D-19) |
| Theme colors | `theme_color: "#0d1117"`, `background_color: "#0d1117"` (D-19) |

**Visual reference (conceptual):**

## Interaction & State Machine

| State | Banner | Settings section | Modal |
|-------|--------|------------------|-------|
| Not engaged | Hidden | Visible (if browser) | Closed |
| Engaged, eligible | Visible | Visible | Closed |
| Dismissed < 7 days | Hidden | Visible | Closed |
| Dismissed ≥ 7 days | Visible again | Visible | Closed |
| Standalone | Hidden | Hidden | Closed |
| iOS banner tap | Hidden until modal closed | — | Open |
| Android install success | Hidden permanently | Hidden | Closed |

**iOS detection:** `navigator.standalone === false` + iOS UA/platform check — show iOS flow, not `beforeinstallprompt` banner variant.

**No blocking first-visit modal** (D-06). Banner only — never intercept first paint.
