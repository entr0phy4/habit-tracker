## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File → parseBackupJson | Untrusted user file bytes enter domain parser only |
| parseBackupJson → importBackup | Only ok:true payloads reach Dexie writes |
| backupService → IndexedDB | Transactional boundary; rollback on throw |
